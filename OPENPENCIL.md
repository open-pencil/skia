# OpenPencil fork notes

This fork is maintained for [OpenPencil](https://github.com/open-pencil/open-pencil).

It carries Skia/CanvasKit patches used by OpenPencil's rendering stack, especially Graphite/Dawn/WebGPU work consumed by [open-pencil/canvaskit-webgpu](https://github.com/open-pencil/canvaskit-webgpu).

Keep upstream history and files as intact as possible; OpenPencil-specific documentation belongs in this file or in the downstream `canvaskit-webgpu` repo.
