# OpenPencil fork notes

This fork is maintained for [OpenPencil](https://github.com/open-pencil/open-pencil).

It carries the Skia/CanvasKit patches OpenPencil's CanvasKit build needs. Patches that are useful beyond OpenPencil should also be offered upstream.

Keep upstream history and files as intact as possible; OpenPencil-specific documentation belongs in this file.
